ProxyDisc: drive disc rating tool for Zenless Zone Zero

Describe a drive disc, its set, slot, main stat and substats, and ProxyDisc grades it from S to F for every agent who can use it. You get a clear keep, maybe or recycle call, so you only spend levelling materials on discs that are worth it.

What it does

  • Scrap or stash rates a disc the moment you pick it up, at any level, and tells you when it beats what an agent is wearing. You can also import a disc straight from a screenshot.
  • Loadouts shows what each agent is wearing, with a build score out of 100, and lets you share a build as an image.
  • My discs keeps a library of the discs you own and who each one suits.
  • Upgrades tracks each roll as you level a disc and shows the best and worst it can still finish at.
  • Agent index lists every agent's recommended 4-piece set, 2-piece options, main stats and substat priority. Each agent also has their own build page.
  • Area patrol ranks cleanup missions and disc sets by how much they would improve the agents you are gearing.

How grading works

A grade is always for one agent, because the same disc can be excellent for one agent and useless for another. It weighs the set, the main stat for slots 4 to 6, and each substat by how high it sits on that agent's priority list. B and above is a disc worth keeping; S is rare by design.
