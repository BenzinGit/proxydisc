ProxyDisc: drive disc rating tool for Zenless Zone Zero

Describe a drive disc, its set, slot, main stat and substats, and ProxyDisc grades it from S to F for every agent who can use it. You get a clear keep, maybe or recycle call, so you only spend levelling materials on discs that are worth it.

What it does

  • Scrap or stash rates a disc the moment you pick it up, at any level, and tells you when it beats what an agent is wearing. You can also import a disc straight from a screenshot.
  • Loadouts shows what each agent is wearing, with a build score out of 100, and lets you share a build as an image.
  • My discs keeps a library of the discs you own and who each one suits.
  • Upgrades tracks each roll as you level a disc and shows the best and worst it can still finish at.
  • Agent index lists every agent's recommended 4-piece set, 2-piece options, main stats and substat priority. Each agent also has their own build page.
  • Area patrol ranks cleanup missions and disc sets by how much they would improve the agents you are gearing.

How grading works

A grade is always for one agent, because the same disc can be excellent for one agent and useless for another. It weighs the set, the main stat for slots 4 to 6, and each substat by how high it sits on that agent's priority list. B and above is a disc worth keeping; S is rare by design. Read the full explanation in How grading works.

No account needed. Everything you save stays in your own browser.

What this is

Describe a drive disc and ProxyDisc tells you which of your agents wants it, and how much. Scrap or stash does that on its own; the other tabs help you keep track of what you own and what each agent is wearing.

The tabs
01
Scrap or stash

Describe a disc you just picked up: set, slot, main stat and substats. If it is already levelled, pick its level and enter the rolls it got. You get a KEEP, MAYBE or RECYCLE call, plus every tracked agent who can use it, graded. From there you can save it, equip it or send it to Upgrades.

02
Loadouts

Every tracked agent as a card with their six slots and a build score out of 100. Click a card to open the editor: pick a slot, then pick a disc from the bay. Clicking a disc without equipping it compares it with what the agent is wearing in that slot. The build guide shows what the agent wants.

03
My discs

Every disc you have saved, as a grid. Click one to see its stats, who can use it, and to delete or upgrade it. Switch to By agent to see which saved discs fit each agent.

04
Upgrades

Pick a saved disc and record each roll as the game gives it to you. The grade updates as you go, and a floor and ceiling show the best and worst it can still finish at, so you know when to stop spending on it.

05
Agent index

Every agent's build: their 4pc set, acceptable 2pc sets, the main stat they want in each slot, and their substat priority. Agents with more than one build have tabs to switch between. This is also where you choose which agents you track.

06
Area patrol

Shows where to farm next. Cleanup missions are ranked by how much their two disc sets would improve the agents you pick, and Best sets ranks every set on its own. Weak and empty slots count most.

07
Backup

Copy a code or download a file so your data survives a cleared browser and can move to another device.

08
Help

This page.

09
Contact

Email a question, a build correction, a bug report or a suggestion to contact@proxydisc.com.

10
Settings

Agent pictures, how much of the background art to show, and which builds, 2pc sets and main stats count when grading. You can also run the first-time setup again here.

Worth knowing
Nothing leaves this browser

There is no account and no server. Everything is stored in this browser, so clearing your browsing data wipes it. Take a backup now and then.

Grades run S to F

A grade is always measured against one agent's build, so the same disc can be an S for one agent and an F for another. It weighs the main stat, how many of the agent's substats it has, and how high each one sits on their list. The number next to a grade is the score behind it, out of 100, so two discs with the same letter can still be told apart.

S AExcellent. Rare, and close to the best a disc can be.
BGood. Worth using and keeping.
CUsable. Fine to wear until you find something better.
D FWeak for this agent. Worth replacing, or better on someone else.

So a B is not a bad result. Don't hold out for S on every slot; B and above is a strong disc.

Unlevelled grades are provisional

A disc below +15 has rolls still to come. Its grade is what it has earned so far, and the ceiling in Upgrades shows how high it could still go.

The build score

Each Loadouts card has a score out of 100 for the whole build. 100 means six perfect discs, which is very rare; empty slots count as zero.

Hide and Only for are opposites

Hide removes a disc from one agent. Only for removes it from everyone else. Either way it stays saved.

A star locks a disc

Starring a disc marks it as one you have decided to keep. It cannot be deleted while the star is on.

Equipping swaps

An agent holds one disc per slot, so equipping into a filled slot takes off whatever was there. That disc is free again straight away.

Ignore a build you will never run

On an agent with more than one build, Ignore drops that build from grading everywhere.

Three-substat discs start a roll behind

A disc with only three substats spends its first upgrade adding the fourth, which a four-substat disc got for free. Grading accounts for this.

ProxyDisc keeps everything in this browser and never sends it anywhere. That also means clearing your browsing data wipes it, and nothing follows you to another device. Take a backup before either happens.
